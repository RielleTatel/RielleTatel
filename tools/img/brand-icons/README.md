# Brand icons

These SVGs are sourced from [Devicon](https://github.com/devicons/devicon),
using the original variant except Django, which uses the plain variant.
Retrieved on 2026-10-11; Supabase, Tailwind CSS, Vite, NestJS, Prisma, Expo,
Cloudflare, Vitest, PHP and C++ added 2026-10-13. The upstream MIT license is included in `LICENSE`.

The About page serves these small assets locally, without a third-party CDN
request or an additional JavaScript icon package.
